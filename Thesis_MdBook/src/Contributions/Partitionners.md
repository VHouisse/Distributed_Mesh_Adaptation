# Partitionners


As discussed, the sheer amount of data generated by solving CFD equations, coupled with the need for high-performance computing, drives us to utilize multiple computing units. To achieve this, it's essential to partition the mesh underlying the computational domain. Partitioning allows us to divide the domain into as many sub-domains as there are available cores, breaking down the initial problem into N sub-problems


Effective partitioning relies on three essential criteria:

Minimizing Interdependencies: Reduce the number of shared edges or faces between sub-domains to limit costly communications between computing units.

Preserving Quality: Ensure that the division doesn't degrade the quality of individual sub-meshes.

Load Balancing: Distribute the computational workload equitably among all processors to avoid bottlenecks and maximize parallel performance (cf. Load Balancing).





### Partitioning for Re-meshing: The Interface Challenge

In the context of re-meshing, managing interfaces between partitions is a major challenge, as these boundaries must be adapted without compromising overall mesh continuity or parallel efficiency. Two main approaches can be distinguished to address this problem:





#### Two-Step process :

This method begins with an initial mesh partitioning. The interfaces of these initial partitions are then "frozen," allowing each processor to re-mesh its internal sub-domain independently. Once this first phase of local adaptation is completed, a second partitioning is performed over the entire domain. This second partitioning is designed so that the frozen interfaces from the first partitioning share no elements in common with the new interfaces of the second partitioning. This strategy ensures that the entire domain, including the interfaces initially frozen in the first phase, is effectively re-meshed, thus ensuring complete adaptation.

#### Hierarchical Interface Freezing Method :

This second approach is also based on interface freezing, but in an iterative and hierarchical manner. The domain is initially partitioned and the interfaces are frozen, allowing for independent re-meshing of each sub-domain. Once this step is complete, attention shifts to the interfaces themselves: they are, in turn, partitioned (by "freezing" the newly created sub-interfaces) and then re-meshed. This process of subdividing and re-meshing interfaces can be repeated recursively (freezing interfaces of interfaces, and so on) until a satisfactory level of precision and conformity is achieved across all boundaries.
